# Reluctant Bowling

A relaxing game of ten-pin bowling. Allegedly.

A single-file three.js + cannon.js browser game. Open `index.html`, or play it via GitHub Pages once enabled for this repo.

- Drag down to swing the ball back, let go to bowl. Swipe up before releasing for more power; a hard swing lobs the ball.
- Drag sideways to line up a shot.

Everything else you'll find out.

## Running locally

Any static server will do, e.g. `python3 -m http.server` then open http://localhost:8000. Libraries (three r128, cannon 0.6.2) load from cdnjs.
